# 📚 Kırtasiye E-Ticaret ve Tanıtım Web Sitesi

Bu proje, Web Tasarımı dersi kapsamında geliştirilmiş; kullanıcı dostu arayüze sahip, kırtasiye ürünlerini tanıtan ve listeleyen örnek bir web sitesidir.

## 🚀 Proje Hakkında
Bu web sitesi, kırtasiye ürünlerine kolayca göz atılmasını sağlamak ve temel web tasarımı prensiplerini uygulamak amacıyla oluşturulmuştur. Projede kullanıcıların ürünleri inceleyebileceği farklı kategoriler ve sayfa yapıları yer almaktadır.

## 🛠️ Kullanılan Teknolojiler
Projenin geliştirilmesinde kullanılan temel teknolojiler:
* **HTML5**
* **CSS3** 
* **Responsive Tasarım Prensipleri**

## Proje Dosya Yapısı
Projeye ait temel HTML ve medya dosyaları şunlardır:
* `index.html` - Ana sayfa
* `buromalzemeleri.html` - Büro malzemeleri sayfası
* `ogrencidostuurunler.html` - Öğrenci dostu ürünler sayfası
* `trendurunler.html` - Trend ürünler sayfası
* `resimler / .webp / .jpg` - Projede kullanılan görsel varlıklar
